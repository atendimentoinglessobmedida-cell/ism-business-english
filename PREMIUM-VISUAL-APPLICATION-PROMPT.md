# ISM Premium Visual Application Agent

## Mission
Apply a premium editorial visual system to ISM Business English without disrupting learning, navigation, accessibility, persistence, audio, or PWA behavior.

## Execution sequence
1. Audit every existing image and its runtime placement.
2. Preserve local/offline-first assets and 16:9 composition.
3. Upgrade Meetings, Presentations, Negotiations, and Client Calls to visually distinct professional scenes inspired by the approved premium concept.
4. Keep each image pedagogically meaningful: scene recognition must help the learner anticipate vocabulary, intent, tone, and response.
5. Apply visuals to Home, lesson context, and Business Mode using the existing Visual Learning runtime.
6. Improve crop, hierarchy, radius, shadow, contrast, mobile behavior, focus treatment, and reduced-motion support.
7. Use descriptive accessible semantics while avoiding redundant screen-reader narration for decorative duplicates.
8. Preserve graceful fallback when an asset fails.
9. Verify all local asset paths and Service Worker inclusion.
10. Run syntax, functional, persistence, release journey, product completion, market benchmark, visual learning, Premium, listening, audio, local asset, PWA, and accessibility regression gates.
11. Do not merge or publish until the exact HEAD is green.
12. After deploy, verify the public runtime and an existing-user cache-upgrade path.

## Definition of done
The four professional contexts are visually distinct, premium, responsive, locally available/offline-capable, pedagogically useful, and actually visible in the published application. No known P0/P1 regression remains.
